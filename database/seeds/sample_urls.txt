# A small, stable, hand-reviewed URL set for integration tests.
#
# `#` begins a comment. This is a seed (~50 URLs is the ceiling), not a crawl.
# CI MUST NOT fetch these URLs. Integration tests run against a local fixture
# origin server so the suite is hermetic and non-abusive.
#
# The set is chosen to exercise the interesting cases: a canonical page, a
# duplicate that differs only by a tracking parameter, a redirect, and a trap.
